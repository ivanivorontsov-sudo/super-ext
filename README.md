# СуперАпп — многофункциональное расширение для Chrome / Edge (Manifest V3)

## Установка (режим разработчика)
1. Распакуйте `super-ext.zip` в любую папку (например, `C:\SuperApp`).
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`).
3. Включите **«Режим разработчика»** (переключатель справа вверху; в Edge — слева).
4. Нажмите **«Загрузить распакованное»** и выберите папку с файлом `manifest.json`.
5. Закрепите значок 📌 на панели. Боковая панель: кнопка «⇥ Панель» в окне расширения.

## Возможности
- **Загрузки**: автопоиск картинок, видео/аудио (включая потоки HLS `.m3u8` и DASH `.mpd`, перехват по сетевым запросам), документов и архивов, таблиц (экспорт в CSV/JSON). Быстрая загрузка в 1–16 потоков (Range-запросы), HLS собирается в `.ts`/`.mp4`, поддержано шифрование AES-128. DRM (Widevine, SAMPLE-AES) не обходится — намеренно.
- **YouTube**: петля всего видео, повтор отрезка A-B, скорость 0,25–16×, лайки/дизлайки через Return YouTube Dislike (это оценка, а не официальные цифры). Скачивание видео с YouTube не поддерживается: потоки защищены, а правила сервиса это запрещают. Можно открыть превью в макс. качестве и скопировать команду `yt-dlp`.
- **Скриншоты**: видимая часть, вся страница (склейка), область; редактор — стрелки, рамки, карандаш, маркер, текст, размытие, обрезка, отмена; PNG/JPEG/буфер обмена.
- **Сохранение страниц**: MHTML (одним файлом с картинками), HTML, PDF (через печать), текст.
- **Мобильный вид**: сайт в рамках Pixel/iPhone/Galaxy/планшета с мобильным User-Agent, поворот.
- **Android**: проверенный список облачных и локальных эмуляторов с оценкой безопасности (настоящий Android в расширении невозможен).
- **Дополнительно**: чистые ссылки без трекеров (utm, fbclid, ysclid…), разблокировка копирования и правого клика, «картинка в картинке», сохранение/закрытие вкладок в сессии с экспортом в JSON и CSV и импортом из JSON, контекстное меню.

## Приватность
Нет телеметрии, рекламы и аналитики. Внешний запрос делается только к returnyoutubedislikeapi.com (передаётся ID видео), его можно отключить в настройках.
Разрешения: `<all_urls>` + `webRequest` — для поиска медиа и загрузки; `pageCapture` — для MHTML; `declarativeNetRequest` — только для фреймов страницы «Мобильный вид»; `scripting/tabs/activeTab` — для скриншотов и сканирования.
